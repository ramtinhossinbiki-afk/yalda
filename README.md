# 🍉 Yalda | شب یلدا

یک تجربه دیجیتال زیبا برای جشن گرفتن طولانی‌ترین شب سال؛ با طراحی شیشه‌ای (Glassmorphism)، رنگ‌های یلدایی و فضایی متفاوت.

## ✨ ویژگی‌ها

- 🎨 طراحی مدرن با افکت شیشه‌ای و پس‌زمینه متحرک
- 🌙 تم تاریک با ترکیب رنگ‌های قرمز، بنفش و طلایی
- 🖼️ گالری تصاویر یلدایی
- 🔍 مشاهده تصاویر در اندازه بزرگ (Lightbox)
- 📥 امکان ذخیره تصاویر
- 🗂️ دسته‌بندی و فیلتر تصاویر
- ⏳ شمارش معکوس تا شب یلدا
- 📱 طراحی واکنش‌گرا برای موبایل و کامپیوتر
- ✨ انیمیشن‌ها و جلوه‌های بصری جذاب

## 🛠️ تکنولوژی‌ها

- HTML5
- CSS3
- JavaScript
- Google Fonts – Vazirmatn

## 🚀 اجرا

برای مشاهده سایت کافی است فایل `index.html` را در مرورگر باز کنید.
